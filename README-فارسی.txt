ساخت APK بازی «نبرد میالند» - مرحله به مرحله (بدون نصب هیچ برنامه‌ای)

۱) در سایت github.com ثبت‌نام کن (رایگان).
۲) روی دکمه + بالا سمت راست بزن > New repository. یک اسم بنویس (مثلاً mialand) و Create repository.
۳) در صفحه‌ی بعد روی لینک «uploading an existing file» بزن.
۴) محتویات این پوشه (نه خود زیپ) را با Drag & Drop داخل صفحه بنداز.
   ⚠ پوشه‌ی مخفی .github هم باید آپلود شود (اگر در ویندوز نمی‌بینی، در File Explorer تیک Hidden items را بزن).
۵) پایین صفحه Commit changes را بزن.
۶) برو به تب Actions. ساخت خودکار شروع می‌شود (حدود ۵ تا ۱۰ دقیقه). اگر شروع نشد: Build APK > Run workflow.
۷) وقتی تیک سبز شد، روی آن بزن و پایین صفحه در بخش Artifacts فایل mialand-arena-apk را دانلود کن.
۸) زیپ را باز کن، app-debug.apk را به گوشی بفرست و نصب کن (اجازه‌ی «نصب از منابع ناشناس» را بده).
